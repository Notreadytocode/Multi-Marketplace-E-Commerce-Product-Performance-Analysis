# Multi-Marketplace E-Commerce Product Performance Analysis

An end-to-end data analytics project analyzing e-commerce product performance across **Lazada, Shopee, Walmart, and SHEIN** using **Python, Pandas, SQL, SQLite, and Matplotlib**.

The project focuses on identifying high-performing products, brands, categories, pricing patterns, customer engagement, discounts, sales volume, and marketplace-level performance.

---

## 📊 Project Overview

E-commerce marketplaces contain millions of products with different pricing structures, ratings, review volumes, sellers, and sales performance.

This project combines product datasets from multiple marketplaces and transforms them into a standardized analytical dataset.

The analysis answers key business questions such as:

- Which marketplace has the largest product catalog?
- Which marketplace has the highest average price?
- Which marketplace has the highest average rating?
- Which products receive the most reviews?
- Which products have the highest sales volume?
- Which products generate the highest GMV?
- Which brands have the strongest product presence?
- Which categories perform best?
- Which marketplace provides the largest discounts?
- Which products combine high ratings with strong customer engagement?
- How does pricing vary across marketplaces?

---

## 🛒 Marketplaces Analyzed

| Marketplace | Data Included |
|---|---|
| Lazada | Products, prices, ratings, reviews, sales, GMV, brands, sellers |
| Shopee | Products, prices, ratings, reviews, sales, GMV, brands, sellers |
| Walmart | Products, prices, ratings, reviews, brands, categories |
| SHEIN | Products, prices, ratings, reviews, brands, categories |

Because each marketplace provides different fields, the datasets were standardized into a common analytical structure before SQL analysis.
